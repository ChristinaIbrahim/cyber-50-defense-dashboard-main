# 📊 Cyber-Security Analytics & Defense Dashboard

A production-grade, highly interactive Cyber Security Dashboard built with **Angular 17** and **D3.js** designed to visualize, track, and analyze complex cybersecurity attack patterns and real-time incidents.

---

### 🛠️ Tech Stack & Architecture

* **Framework:** Angular 17 (Component-driven development, Lazy Loading)
* **Data Visualization:** D3.js (Dynamic, scalable charts & matrix mapping)
* **Styling:** Tailwind CSS (Responsive utility-first design)
* **State Management & Async Operations:** RxJS Observables & Reactive Streams

---

### 🚀 Key Features

* **Interactive Visualizations:** 6 modular visualization panels depicting security statistics, origin locations, and threat severity levels.
* **Real-time Filtering:** High-performance dynamic data sorting and filtering without UI lagging.
* **Incident Analytics:** Specialized dashboard telemetry tracking 1000+ mock cyber incidents.
* **Data Management:** Built-in capability for CSV data export and custom JSON dataset parsing.
* **Performance Optimized:** Optimized Angular change detection and Core Web Vitals for low-latency rendering.
